Sistema web desenvolvido para gerenciamento e controle da validade de produtos.

🔗 [Ver projeto](https://github.com/brenohnrq01-ux/SCV--Sistema_de_Controle_de_Validade)

### Principais funcionalidades

- Registro de usuários responsáveis pelas operações

- Relatórios mensais de perdas
- Integração com banco de dados

`Next.js` `React` `TypeScript` `Tailwind CSS` `Supabase` `PostgreSQL`
